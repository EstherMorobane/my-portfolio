# Matseliso Morobane – Portfolio

A responsive personal portfolio website built with HTML and CSS.

## Open the website
1. Keep `index.html` and `styles.css` in the same folder.
2. Open `index.html` in a web browser.

## Add your profile picture
1. Open the portfolio folder.
2. Create a folder named `images` if it does not already exist.
3. Copy your photo into that folder and name it `profile.jpg`.
4. The image path used by the website is `images/profile.jpg`.

Use a clear head-and-shoulders photo. JPG or JPEG is recommended; if your photo has a different file extension, either rename it to `profile.jpg` or update the `src` value in `index.html` to match the exact filename.

## Edit
Open the folder in Visual Studio 2022 using **File > Open > Folder**. Edit `index.html` for content and `styles.css` for appearance.
